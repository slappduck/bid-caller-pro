# Environment variables

Every variable the backend (`license_server/`) reads, so this never has to be
reconstructed from Render's dashboard alone. Generated by grepping every
`os.environ.get(...)` call in `license_server/*.py` — the defaults below are
copied directly from the code, not guessed.

Nothing here is a secret value, only names, defaults, and what each is for.
The real values live in Render's Environment tab, never in this repo.

## Required — set these on Render, or the feature they gate does not work

None of these have a working default (the code reads `os.environ.get("NAME", "")`
— an empty string), so the feature is either broken or fully disabled without
them.

| Variable | What it's for |
|---|---|
| `SUPABASE_URL`, `SUPABASE_ANON_KEY`, `SUPABASE_SERVICE_ROLE_KEY` | Customer auth and the terms-acceptance/account tables. Core to sign-in working at all. |
| `UPSTASH_REDIS_REST_URL`, `UPSTASH_REDIS_REST_TOKEN` | Persistence layer for license/scan-cache data that must survive Render restarts (Render's own disk does not). Falls back to a local JSON file if unset — fine for dev, lost on every redeploy in production. |
| `ADMIN_EMAILS` | Comma-separated allowlist. An email on this list gets permanent, unlimited access — no license key or trial needed. (This is the mechanism we looked at earlier tonight.) |
| `CRON_SECRET` | Shared secret the GitHub Actions scheduled jobs (`.github/workflows/*.yml`) send so `/run-*` endpoints know the request is a real scheduled job and not a stranger. |
| `RESEND_API_KEY`, `FROM_EMAIL` | Outbound transactional email (license delivery, reminders, alerts) via Resend. `FROM_EMAIL` has a Resend sandbox default that only delivers to your own verified address — a real domain needs to be verified with Resend for this to reach customers. |
| `STRIPE_WEBHOOK_SECRET` | Verifies incoming Stripe webhook signatures (payments, referral bonuses). Without it, Stripe events are rejected. |
| `MAILING_ADDRESS` | The physical postal address the campaign-email system signs with. CAN-SPAM requires a real one on every commercial email; the code refuses to send without it. |
| `SITE_ORIGINS` | CORS allowlist — which frontend origins are allowed to call this API. |
| `SAM_API_KEY` | Federal opportunities (SAM.gov) integration. Without it, that one bid source is simply unavailable — everything else still works. |
| `TAVILY_API_KEY`, `OPENAI_API_KEY` | The paid search + page-reading path for local bid discovery. Without them the free-tier search providers (Google CSE, DuckDuckGo, direct portal scraping) still run — this is a coverage/quality tier, not a hard dependency. |

## Keeping this current

This list was built by grepping `license_server/*.py` for every
`os.environ.get(...)` call. If you add a new one, run this to check whether
this doc is still complete:

```bash
grep -hoE 'os\.environ\.get\("[A-Z_]+"' license_server/*.py | sort -u
```
